# SHf_UEVR
A VR first person mod for UEVR when playing Silent Hill f

## Features
- Full 1st person 6DOF Motion controls
- Full visible body
- Optional IK arm or hands
- Cutscene fixes
- Control scheme adjustments for VR
- In game tutorial
- Interact with doors, ladders and levers with physical gestures
- Pick up items with physical gestures
- Holster, swap weapons, heal, open inventory and map with physical gestures

## Notes
Long press L3+R3 for at least 3 seconds to open the UEVR overlay so as not to interfere with the game's native L3+R3 handling
